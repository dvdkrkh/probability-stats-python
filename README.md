# Теория вероятностей и статистика на Python

Разбираю теорию вероятностей и математическую статистику через симуляции на Python.
Каждый ноутбук — одна тема: коротко теория, эксперимент в коде, сравнение с формулами и выводы.

## Ноутбуки

| № | Тема | Что внутри |
|---|------|------------|
| 01 | [Распределения случайных величин](01_distributions.ipynb) | Биномиальное, равномерное, показательное и нормальное распределения: симуляция против теории, правило трёх сигм, функция Лапласа |

## Стек

Python, NumPy, SciPy, Matplotlib, Jupyter

## Как запустить

```bash
pip install -r requirements.txt
```

Затем открыть нужный ноутбук в Jupyter или VS Code и запустить все ячейки.
